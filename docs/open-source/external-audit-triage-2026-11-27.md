# External audit triage, 27 November 2026

Two external reviews examined a changing pre-release checkout. The tables identify the reported behavior, the change in this source tree and any deployment work that remains. S, OS and B refer to the first review’s security, publication and functional findings. P refers to the numbered findings in the second review.

**Evidence.** Targeted Go race tests ran with PostgreSQL required, a local provider simulator and disposable databases. They exercised domain ownership, revocation during upload, quota rejection, MFA, database privileges, worker concurrency, event correlation, suppression and retention. The infrastructure findings below describe template changes. Operators still need to test their actual ingress, IAM grants, TLS configuration and provider behavior before enabling production traffic. The reported live SES header-merging behavior and production outage scenarios were not demonstrated.
